# Coffee Shop Landing Page

A modern, responsive landing page for a coffee shop, created as a team project. This project showcases a beautiful user interface with sections for welcome, quality, experience, testimonials, and location information.

## 🌐 Live Demo

**[View Live Demo](https://den0203.github.io/coffe-joy/)**

## 📋 Description

This is a collaborative team project where we developed a fully responsive coffee shop landing page. The website features a clean design with smooth animations, mobile menu functionality, and an engaging user experience. As part of this project, I was responsible for developing the footer section and served as the Scrum Master, coordinating team activities and ensuring smooth project delivery.

## 🚀 Technologies

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with custom properties
- **JavaScript** - Interactive functionality
- **Vite** - Build tool and development server
- **Swiper.js** - Touch slider for testimonials
- **Body Scroll Lock** - Modal scroll management
- **Modern Normalize** - CSS reset
- **GitHub Pages** - Deployment platform

## ✨ Features

- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ Mobile navigation menu
- ✅ Hero section with call-to-action
- ✅ Welcome and quality information sections
- ✅ Customer testimonials slider
- ✅ Location map integration
- ✅ Newsletter subscription form
- ✅ Modal windows
- ✅ Smooth scrolling and animations
- ✅ Cross-browser compatibility

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/den0203/coffe-joy.git

# Navigate to project directory
cd coffe-joy

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
